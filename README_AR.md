# Game Guard – مشروع أندرويد تجريبي

## الوظيفة
- ضغطتان على رفع الصوت: يطلب من Android تعطيل شريط الحالة.
- ضغطتان على خفض الصوت: يعيد شريط الحالة.
- التقاط الأزرار يتم عبر AccessibilityService مع `FLAG_REQUEST_FILTER_KEY_EVENTS`.

## متطلبات مهمة جداً
إخفاء/تعطيل شريط الحالة على مستوى النظام عبر `DevicePolicyManager.setStatusBarDisabled()` متاح لتطبيق **Device Owner** فقط. تثبيت APK وحده لا يكفي، ولا يمكن لتطبيق عادي تجاوز قيود أندرويد. قد تختلف النتيجة حسب إصدار أندرويد والشركة المصنّعة.

## البناء
1. افتح المجلد في Android Studio (Giraffe أو أحدث).
2. دع Gradle يزامن المشروع.
3. ابنِ APK من Build > Build Bundle(s) / APK(s) > Build APK(s).

## إعداد Device Owner (للمطور/جهاز اختبار فقط)
**تحذير:** أمر تعيين Device Owner عادة لا يعمل إذا كان الجهاز مُعدّاً مسبقاً أو عليه حسابات/إدارة حالية، وقد يتطلب إعادة ضبط المصنع. لا تنفذه على جهازك الأساسي قبل فهم تبعاته.

بعد تثبيت التطبيق على جهاز اختبار نظيف، نفّذ من الكمبيوتر:
```bash
adb shell dpm set-device-owner com.example.gameguard/.GuardAdminReceiver
```
للتحقق:
```bash
adb shell dpm list-owners
```

## تفعيل اختصار الأزرار
من التطبيق اضغط «فتح إعدادات إمكانية الوصول»، ثم فعّل خدمة Game Guard يدوياً. أندرويد يعرض تحذير صلاحية إمكانية الوصول لأن الخدمة تراقب ضغطات المفاتيح.

## ملاحظات
- الخدمة تستهلك ضغطات رفع/خفض الصوت أثناء تفعيلها كي تلتقط الضغطتين؛ لذلك الضغط المفرد لن يغيّر مستوى الصوت.
- هذا مشروع مصدر قابل للبناء وليس APK جاهزاً. لا أستطيع ضمان منع لوحة الإشعارات على كل جهاز قبل اختباره فعلياً عليه.
